# Statistical analysis

## Stage status

This stage is planned as a separate part of the project. It will examine selected business questions using statistical methods, beyond the descriptive summaries presented in the exploratory data analysis.

## Planned documentation

As the analysis is completed, this document will record:

- The statistical questions and hypotheses.
- The variables and groups being compared.
- The statistical tests or methods selected and why they are appropriate.
- Relevant assumptions and checks.
- Test statistics, p-values, effect sizes or confidence intervals where applicable.
- Interpretation in the context of the simulated pharmacy business.
- Limitations and implications for subsequent analysis.

Statistical analysis will remain distinct from exploratory data analysis and predictive modelling.
