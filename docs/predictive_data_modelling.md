# Predictive data modelling

## Stage status

This stage covers the development and evaluation of predictive models for short-term pharmacy product demand. The modelling work will be documented separately from statistical analysis.

## Planned documentation

As the modelling work is finalised, this document will record:

- The prediction objective, target and forecast horizon.
- The modelling dataset and feature definitions.
- Data splitting strategy and prevention of target leakage.
- Baseline model and candidate algorithms.
- Model training, tuning and validation approach.
- Performance metrics on validation and test data.
- Error analysis and interpretation.
- Model limitations and how the results could inform replenishment planning.

Model performance must be interpreted in the context of the simulated data and should not be presented as evidence of real-world pharmacy forecasting performance.
